# miniguia-notebooklm
Miniguia criado no bootcamp da DIO com o Bradesco.
Contexto e Objetivos: Escolhi fazer o miniguia com conteúdo cobrado em concursos públicos. Peguei algumas provas de uma banca específica e pedi uma apostila com o conteúdo que caiu nas provas.

Curadoria de Fontes: Peguei as provas direito do site da banca. https://www.fundatec.org.br/portal/concursos/provas_anteriores.php?concurso=

Engenharia de Prompts e "Cicatrizes": Um dos prompts utilizados foi "Se eu fornecer as provas e uma lista de tópicos, tu consegue retornar quantas questões de cada tópico?". A resposta resumida foi SIM e pediu para eu enviar a lista de assuntos cobrados no edital, então enviei a lista. O Notebook retornou a lista como pedido. Outro prompt utilizado foi "Com base nas questões enviadas, procure as respostas em livros consagrados, caso tenha dúvida se o livro é confiável, pergunte-me. Nos comandos das questões, eles explicam alguns conceitos, pegue-os. Pegue também os conceitos em questões do tipo V ou F. Caso não tenha conseguido descobrir a resposta de alguma questão, ignore-a, não é para inventar coisas. Retorne uma apostila em .pdf com os tópicos:" Depois dos dois pontos eu colei o conteúdo do edital.
